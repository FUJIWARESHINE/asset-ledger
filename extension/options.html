这个扩展做什么、不做什么

  • 不做页面抓取：不注入内容脚本、不读 DOM、不在平台上发任何请求。你在平台上浏览时它完全沉默。
  • 不做平台 API 同步：不存 token、不代你登录，台账里也没有能进账号的凭据。
  • 唯一的浏览器读取动作是「取当前页地址」按钮 —— 只读地址栏里的 URL，和你自己复制一样。
  • 所有已填内容先存在扩展本地队列里，点「全部导入」才真正 POST 到你的台账。
  • 只申请 storage（存队列与配置）和 activeTab（点按钮时读一次地址）两项权限。
